# MethodActor-Studio (方法派·多智能体电影级表情工坊)

> v1.0.1 | 2026-05-30

一个面向 AI 视频创作者的**微表情提示词智能生成系统** (专为 **Seedance 2.0** 语法深度优化)。

它不是单纯帮您堆砌一些“哭泣”、“愤怒”等表面形容词，而是像一位在好莱坞工作了 58 年的老戏骨一样，协同面部解剖学家与 AIGC 导演，解构人类灵魂深层的心理活动、肌肉运动和生理变化，将其翻译成极具感染力的电影级面部动作提示词。

```text
用户情绪输入 (如: 强颜欢笑的绝望崩塌)
-> 老戏骨 · 心理剖析师 (解构心理防御、潜台词与呼吸)
-> 面部解剖学家 · 微表情控制师 (映射医学级肌群与生理水分渗出)
-> Seedance 2.0 导演 · 镜头剪辑师 (分时间轴包装、渲染标准适配)
-> 最终输出：时间轴分段时间码 + 连续叙事流 + 表演教学笔记
```

## 它解决什么问题

这个 skill 主要解决 AI 视频人物表情生成中的 6 大痛点：

1. **表情呆滞无神**：AI 人物通常只会直视镜头、死板地眨眼或机械扭动，缺乏复杂的心理动态。
2. **缺乏层次与阻力**：真正的悲伤或愤怒往往伴随自我克制（如想哭却憋住，想笑却眼神死寂），普通提示词写不出肌肉间的“拉扯与抗争”。
3. **缺少医学级肌肉群控制**：不知道如何调用额肌、皱纹肌、眼轮匝肌、颏肌、笑肌、咬肌等专业肌群去规范 AI 的动作。
4. **遗漏高感染力的生理细节**：忽略了如泪水在眼眶聚积、顺泪痕滑落、鼻孔翕动、鼻腔清涕、嘴角口水丝 (1-2cm) 等极其写实的生理渗出。
5. **时间轴演变脱节**：无法精确控制视频在前 2 秒、中 5 秒、后 3 秒之间的微表情流畅演变，画面过渡容易突变或变形。
6. **导演话术偏泛化**：传统提示词常写“拍得震惊一点”，但 AI 模型只认物理层面的视觉指令，本 Skill 完美架起了“抽象情绪”到“视觉指令”的桥梁。

## 核心定位

`method-actor-studio` 是一个 **专业微表情垂类协同与生成式工作台**。

```text
AI 视频表情呆板
-> 注入好莱坞方法派灵魂 (老戏骨)
-> 精确面部肌肉医学控制 (解剖学)
-> 适配 Seedance 2.0 工业语法 (导演剪辑)
```

它不替代您已有的上游剧本或下游综合提示词工具。它的正确定位是：
* **在您的 AIGC 影视工作流中**，单独承接**“核心演员特写/微表情爆发镜头”**的深度创作，为视频的“灵魂帧”注入饱满的张力。

---

## 多智能体协同（MAS）架构

本系统在运作时，模拟了三个奥斯卡级专业角色的协同推理过程：

* **🎭 老戏骨 · 心理剖析师 (The Method Actor)**
  * **职责**：基于 58 年方法派表演经验，解构情绪背后的“潜台词”与防线突破点，设计合理的呼吸节奏、眼神对焦轨迹（如横向短促扫视、涣散失焦）。
* **🧠 面部解剖学家 · 微表情控制师 (Facial Anatomist)**
  * **职责**：将老戏骨的心路历程精准映射为面部解剖肌肉的拉扯。精细控制额肌 (Frontalis)、皱眉肌 (Corrugator)、眼轮匝肌 (Orbicularis oculi)、颏肌 (Mentalis)、颧大肌 (Zygomatic major)、咬肌 (Masseter) 等肌群，并注入眼泪决堤、鼻翼翕动、冷汗、口水丝等真实生理反应。
* **🎬 Seedance 2.0 导演 · 镜头剪辑师 (Prompt Director)**
  * **职责**：合并上面的灵魂与肌肉，打包成适配 Seedance 2.0 语法规范的最终双格式提示词，确保包含电影级特写、柔和自然光、纯色背景、无对话、25fps、4K 等影院级渲染硬指标。

## 核心功能与输出物

系统将为您交付以下三件套输出：

### 1. 🎭 58年戏骨·表演艺术讲堂 (Directorial Notes)
提供深刻的“体验派”表演知道。例如在“崩溃失控”中：
> *“孩子，这场戏最难的部分不是哭，而是『阻力』。人类在悲伤到极致时，本能反应是试图去克制。第一秒，你要死死咬住牙关，别让下唇颤抖；第二秒，眼泪要像洪水冲破大坝一样决堤。这不只是脸在动，是你的灵魂在痉挛。”*

### 2. ⏱️ 时间轴分动格式提示词 (Timeline Segmented)
将情绪完美分段（如 `0-3s 极度隐忍` $\rightarrow$ `3-7s 防线破裂` $\rightarrow$ `7-10s 完全失控`），每一秒对应明确的肌群位移与生理变化，实现极其自然的微表情平滑过渡。

### 3. 🌊 连续叙事流格式提示词 (Continuous Narrative Stream)
将表情变化烘焙成一段极富文学美感与视觉张力的连贯镜头指令，高度适配更偏好流式描述的 AI 视频大模型。

## 怎么使用

### 1. 启动本地交互式 Web 终端

项目基于 **Vite + React** 搭建，配备了极致质感的 **Midnight Onyx (午夜深蓝)** 影院风控制台。您可以直接在本地可视化操作：

```bash
# 启动本地服务
npm run dev
```
打开链接（通常是 `http://localhost:5173`），您可以：
- 快速测试 5 大表情预设（崩溃破防、皮笑肉不笑假笑、心酸释然、隐忍怒火、绝望强颜欢笑）。
- 自定义输入任何您想表达的情绪，调整焦段、光影、视频背景与时长，实时观看 Agent 协同推理并一键复制提示词。

### 2. 智能体间调用

将下面这一段指令发给您的 Cursor, Codex, OpenClaw, Hermes 或 Claude，即可在任意 Agent 侧快速复用本套方法论：

```text
请调用 method-actor-studio。

情绪：[在此输入您想表达的复杂人物情绪，如：表面坚强内心极度委屈的哽咽]
参数：时长 10s, 电影级面部特写, 柔和自然光, 暗色微虚化背景

请在后台运行多智能体协同推理，最终交付：
1. 戏骨表演讲堂 (Directorial Notes)
2. 呼吸控制建议
3. 时间轴分段提示词 (Timeline Format)
4. 连续叙事流提示词 (Continuous Stream)
```
